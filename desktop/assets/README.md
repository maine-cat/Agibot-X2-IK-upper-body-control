# 双臂显示网格

`arm_meshes.json` 仅用于桌面 MDI 的三维反馈。它不参与 IK、运动指令、碰撞检测、TCP 标定或精度验证。

显示范围为双臂 14 个连杆的简化网格，参考坐标系为 `torso_link`。腕端包含延伸外壳，外观可能与具体装配不同。末端工具以 TCP 原点和方向轴表示，不显示手指或夹爪本体。

网格姿态由关节反馈计算。反馈过期或断开时清空显示；模型不可用时显示骨架。TCP 配置只改变工具原点和方向轴，不改变臂连杆的姿态。
